# Todo App – Clean Architecture (React + TypeScript) ✅

This project is a **Todo application** built using **React** and **TypeScript**, designed specifically to understand and practice **Clean Architecture principles** in a frontend application.

The focus of this project is **code quality, separation of concerns, scalability, and maintainability**, rather than just UI.

---

## 🚀 Tech Stack

- React
- TypeScript
- JavaScript (ES6+)
- HTML5
- CSS3

---

## ✨ Features

- Create new todos
- View todo list
- Update existing todos
- Delete todos
- Full CRUD functionality
- Strong type safety using TypeScript
- Clean Architecture layered design
- Separation of UI, business logic, and data access
- Scalable and maintainable codebase

---

## 🧠 Architecture Concepts Used

- Clean Architecture
- Separation of Concerns
- Dependency Inversion Principle
- Use Cases (Business Logic Layer)
- Entities (Domain Models)
- Interfaces & Abstractions
- Framework-independent business logic
